## 3. 文件秒传机制

### 3.1 工作流程

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  选择文件     │────▶│  计算SHA256   │────▶│  检查秒传     │
└──────────────┘     └──────────────┘     └──────┬───────┘
                                                  │
                          ┌───────────────────────┼───────────────────────┐
                          │                                               │
                          ▼                                               ▼
                   ┌──────────────┐                                ┌──────────────┐
                   │  文件已存在   │                                │  文件不存在   │
                   │  直接使用URL  │                                │  正常上传     │
                   └──────────────┘                                └──────────────┘
```

### 3.2 API 端点

#### POST `/v2/files/check` — 秒传检查

**请求体**:

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `sha256` | String | ✅ | 文件SHA256哈希 |
| `size_bytes` | long | ✅ | 文件大小（字节） |

**请求示例**:
```json
{
  "sha256": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855",
  "size_bytes": 1048576
}
```

**响应（文件已存在）**:
```json
{
  "exists": true,
  "url": "/uploads/media/e3b0c442.jpg"
}
```

**响应（文件不存在）**:
```json
{
  "exists": false,
  "url": null
}
```

### 3.3 SHA256 计算

```java
private String calculateSHA256(Uri fileUri) {
    try {
        MessageDigest digest = MessageDigest.getInstance("SHA-256");
        InputStream is = getContentResolver().openInputStream(fileUri);
        byte[] buffer = new byte[8192];
        int read;
        while ((read = is.read(buffer)) != -1) {
            digest.update(buffer, 0, read);
        }
        is.close();
        byte[] hash = digest.digest();
        return bytesToHex(hash);
    } catch (Exception e) {
        return null;
    }
}
```

### 3.4 秒传优势

| 指标 | 无秒传 | 有秒传 |
|---|---|---|
| 重复文件上传时间 | 完整上传 | <100ms |
| 流量消耗 | 完整文件大小 | 仅SHA256请求 |
| 服务器存储 | 重复存储 | 去重存储 |
| 用户体验 | 等待上传 | 瞬间完成 |

## 4. 文件上传端点

### 4.1 POST `/v2/files/upload` — 文件上传v2

替代旧的 `/files/upload`、`/v1/files/upload`。

**Content-Type**: `multipart/form-data`

**请求参数**:

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `file` | binary | ✅ | 文件二进制数据 |
| `sha256` | String | ❌ | 文件SHA256哈希 |
| `mime` | String | ❌ | MIME类型 |

**成功响应**:
```json
{
  "url": "/uploads/media/photo_123.jpg",
  "filename": "photo.jpg",
  "size": 102400,
  "mime": "image/jpeg",
  "original_url": "/uploads/media/photo_123.jpg",
  "file_upload_base_url": "https://cdn.oldchat.com/uploads"
}
```

**响应字段**:

| 字段 | 类型 | 说明 |
|---|---|---|
| `url` | String | 文件URL |
| `filename` | String | 文件名 |
| `size` | long | 文件大小（字节） |
| `mime` | String | MIME类型 |
| `original_url` | String | 原始URL |
| `file_upload_base_url` | String | 上传基础URL |

### 4.2 POST `/v2/resources/upload` — 资源上传v2

替代旧的 `/resources/upload`。

**Content-Type**: `multipart/form-data`

**请求参数**:

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `file` | binary | ✅ | 文件二进制数据 |
| `type` | String | ✅ | 资源类型（如 `"avatar"`） |
| `sha256` | String | ❌ | 文件SHA256哈希 |

**成功响应**: 同 `/v2/files/upload`

## 5. 完整上传流程

```java
public void uploadFile(Uri fileUri, UploadCallback callback) {
    // 1. 获取文件信息
    String mimeType = getMimeType(fileUri);
    long fileSize = getFileSize(fileUri);
    
    // 2. 计算SHA256
    String sha256 = calculateSHA256(fileUri);
    
    // 3. 检查秒传
    FileCheckRequest checkRequest = new FileCheckRequest();
    checkRequest.setSha256(sha256);
    checkRequest.setSize_bytes(fileSize);
    
    api.checkFile(checkRequest).enqueue(new Callback<FileCheckResponse>() {
        @Override
        public void onResponse(...) {
            if (response.isSuccessful() && response.body().isExists()) {
                // 4a. 秒传成功
                callback.onSuccess(response.body().getUrl());
            } else {
                // 4b. 正常上传
                performUpload(fileUri, sha256, mimeType, callback);
            }
        }
    });
}

private void performUpload(Uri fileUri, String sha256, String mime, 
                            UploadCallback callback) {
    File file = uriToFile(fileUri);
    RequestBody requestFile = RequestBody.create(MediaType.parse(mime), file);
    MultipartBody.Part filePart = MultipartBody.Part.createFormData(
        "file", file.getName(), requestFile);
    
    RequestBody sha256Body = sha256 != null ? 
        RequestBody.create(MediaType.parse("text/plain"), sha256) : null;
    RequestBody mimeBody = RequestBody.create(MediaType.parse("text/plain"), mime);
    
    api.uploadFileV2(filePart, sha256Body, mimeBody)
        .enqueue(new Callback<UploadResponseV2>() {
            @Override
            public void onResponse(...) {
                if (response.isSuccessful()) {
                    callback.onSuccess(response.body().getUrl());
                } else {
                    callback.onError("上传失败");
                }
            }
        });
}
```
