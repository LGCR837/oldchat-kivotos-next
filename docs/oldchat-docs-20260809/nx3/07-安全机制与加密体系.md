## 2. Conscrypt TLS 库 (版本变化) ⭐

### 2.1 版本状态

| 特性 | 正式版 (release) | 测试版 (dev2) |
|---|---|---|
| Conscrypt | ✅ 有 (156个Java文件) | ❌ 已移除 |
| TLS实现 | Conscrypt (原生JNI) | Java标准TLS + SpongyCastle |
| 原生库 | libconscrypt_jni.so (4个ABI) | 无 |
| TLS版本 | 1.0-1.3 (原生支持) | 依赖系统版本 |

**正式版** 引入了完整的 **Conscrypt TLS/SSL 库** (`org.conscrypt` 包，156个Java文件)，通过原生 JNI 库提供硬件加速的加密运算。所有 oldchat 包下的类都 `import org.conscrypt.BuildConfig`。

**测试版** 移除了 Conscrypt，改用 Java 标准 TLS 实现。SpongyCastle 大幅扩展，新增 SM2/SM9 国密算法支持。移除原生库后 APK 体积从 6.7MB 降至 4.6MB。

## 3. 加密库: SpongyCastle

### 3.1 简介

SpongyCastle 是 BouncyCastle 加密库的 Android 移植版本，通过重命名包名 (`org.spongycastle`) 来避免与系统内置 BouncyCastle 冲突。

### 3.2 版本变化

| 特性 | 正式版 (release) | 测试版 (dev2) |
|---|---|---|
| 包大小 | 基础加密 | 大幅扩展 |
| 国密SM2 | ❌ | ✅ SM2Engine, SM2Signer |
| 国密SM9 | ❌ | ✅ SM9Engine |
| 测试类 | 少量 | 大量新增 |

### 3.3 使用场景

| 功能 | SpongyCastle 类 | 用途 | 版本 |
|---|---|---|---|
| ECDH密钥协商 | ECKeyPairGenerator, ECDHBasicAgreement | 端到端加密握手 | — |
| SHA哈希 | SHA1Digest, SHA256Digest | 数据完整性校验 | — |
| AES加密 | AESEngine, CBCBlockCipher | 消息加密 | — |
| RSA签名 | RSAEngine | 数字签名 | — |
| Base64 | Base64 | 编码传输 | — |
| 随机数 | SecureRandom | 密钥生成 | — |
| **SM2加密** | SM2Engine | 国密SM2公钥加密 | **dev2新增** |
| **SM2签名** | SM2Signer | 国密SM2数字签名 | **dev2新增** |
| **SM9加密** | SM9Engine | 国密SM9基于标识加密 | **dev2新增** |

### 3.4 SM2/SM9 国密算法 (dev2新增)

SM2 和 SM9 是中国国家密码标准:

- **SM2**: 基于椭圆曲线的公钥密码算法，类似 ECDSA/ECDH
- **SM9**: 基于标识的公钥密码算法 (Identity-Based Encryption)

```java
// SM2 签名示例
SM2Signer signer = new SM2Signer();
signer.init(true, new ParametersWithID(privateKey, id));
signer.update(data, 0, data.length);
byte[] signature = signer.generateSignature();

// SM9 加密示例
SM9Engine engine = new SM9Engine();
engine.init(true, publicKey);
byte[] encrypted = engine.processBlock(data, 0, data.length);
```

国密支持的加入意味着测试版可能面向中国市场，需要符合国家密码标准合规要求。

## 4. ECDH 密钥协商

### 4.1 协议概述

ECDH (Elliptic Curve Diffie-Hellman) 是一种基于椭圆曲线的密钥协商协议，允许双方在不安全的通道上协商出共享密钥。

### 4.2 在 OldChat 中的应用

推测 OldChat 使用 ECDH 实现端到端加密 (E2EE):

```
用户A                           用户B
  │                               │
  │ 生成密钥对 (a, A=aG)          │ 生成密钥对 (b, B=bG)
  │                               │
  │ ──── 发送公钥 A ────────────→ │
  │ ←──── 发送公钥 B ──────────── │
  │                               │
  │ 计算共享密钥:                  │ 计算共享密钥:
  │ S = aB = abG                  │ S = bA = abG
  │                               │
  │ ──── S 相同，握手完成 ────    │
```

## 5. 认证机制

### 5.1 Token 认证流程

```
1. 用户登录
   POST /auth/login {identifier, password, device_id, ...}
   ↓
2. 服务端返回
   {access_token, refresh_token, user: {id, uid, ncuid}}
   ↓
3. 客户端存储
   SharedPreferences("auth").putString("access_token", token)
   SharedPreferences("auth").putString("my_ncuid", ncuid)
   ↓
4. API请求携带
   Authorization: Bearer <access_token>
   ↓
5. Token过期
   使用 refresh_token 获取新的 access_token
```

### 5.2 Token 存储

| 键 | 值 | 风险 |
|---|---|---|
| access_token | JWT Token (明文) | 中 |
| refresh_token | Refresh Token (明文) | 中 |
| KEY_ACCESS_TOKEN | Token键名 (v1.4.x配置化) | — |

### 5.3 登录安全

登录请求体:
```json
{
    "identifier": "用户名",
    "password": "密码",
    "device_id": "设备唯一ID",
    "imei": "IMEI号",
    "device_name": "设备型号",
    "platform": "android",
    "app_version": "1.4.x"
}
```

### 5.4 设备绑定

登录时携带设备信息 (device_id, imei, device_name)，服务端可进行设备绑定和异常检测。

### 5.5 注册流程变化 (v1.4.x, jadx 确认)

| 版本 | 注册方式 | 实现 |
|---|---|---|
| v1.3.61 | `RegisterActivity` → POST `/auth/register` | 应用内注册表单 |
| v1.4.x | `LoginActivity` → 浏览器跳转 `/register` | 外置到浏览器 |

```java
// v1.4.x LoginActivity 中的注册跳转
Intent intent = new Intent(Intent.ACTION_VIEW, Uri.parse(base_url + "/register"));
startActivity(intent);
```

## 7. 安全风险清单

### 7.1 高风险

| 风险 | 说明 | 影响 |
|---|---|---|
| **明文密码存储** | `saved_password` 以明文存储在 SharedPreferences | 设备被Root或备份后密码泄露 |
| **明文HTTP流量** | `usesCleartextTraffic=true` | 中间人攻击可截获Token和密码 |
| **allowBackup=true** | 应用数据可通过ADB备份 | 攻击者可提取所有本地数据 |

### 7.2 中风险

| 风险 | 说明 | 影响 |
|---|---|---|
| Token明文存储 | access_token 未加密 | 设备被Root后Token泄露 |
| IMEI收集 | 登录时发送IMEI | 隐私问题 |
| 无证书固定 | 未发现Certificate Pinning | 中间人攻击可能性 |

### 7.3 正面变化 (v1.4.x, jadx 确认)

| 变化 | 影响 |
|---|---|
| **Conscrypt TLS集成** (156个Java文件) | 统一TLS实现，支持TLS 1.3 |
| **Certificate Transparency** | 证书透明度检查 |
| **硬件加速加密** | JNI原生库加速 |
| **9u.pem证书文件** | 新增证书资源 |

## 8. 安全建议

### 8.1 存储安全

```
当前: SharedPreferences (明文)
建议: EncryptedSharedPreferences (AndroidX Security)
     或 Android Keystore + 加密存储
```

### 8.2 传输安全

```
当前: usesCleartextTraffic=true
建议: 设置为 false，强制HTTPS
     添加 Network Security Config
     实施 Certificate Pinning
```

### 8.3 备份安全

```
当前: allowBackup=true
建议: 设置为 false
     或使用 android:fullBackupContent 排除敏感文件
```
