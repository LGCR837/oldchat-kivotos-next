# 10 - 交互按钮系统 (dev2新增)

> 基于 jadx 反编译分析 (oldchat-dev-new.apk)  
> 更新时间: 2026年8月  
> 交互按钮系统是 dev2 版本引入的全新消息交互功能

---

## 1. 概述

交互按钮系统允许在消息中嵌入可点击的按钮，类似 Telegram Inline Keyboard。支持多种按钮样式、分组布局和表单数据提交。

**功能特性**:
- 消息内嵌按钮
- 多种按钮样式（primary, danger, default）
- 按钮分组（行布局）
- 表单数据支持
- 事务ID追踪
- Nonce防重放

---

## 2. 消息格式

### 2.1 基本结构

当 `msg_type === "interactive"` 时，body 包含按钮定义:

```json
{
  "msg_type": "interactive",
  "body": {
    "text": "请选择操作",
    "buttons": [
      [
        {"text": "同意", "action": "approve", "type": "primary"},
        {"text": "拒绝", "action": "reject", "type": "danger"}
      ]
    ]
  }
}
```

### 2.2 字段详解

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `msg_type` | String | ✅ | 消息类型，固定为 `"interactive"` |
| `body.text` | String | ✅ | 消息文本内容 |
| `body.buttons` | Array<Array> | ✅ | 按钮组（二维数组） |
| `body.buttons[][].text` | String | ✅ | 按钮显示文本 |
| `body.buttons[][].action` | String | ✅ | 按钮动作标识 |
| `body.buttons[][].type` | String | ✅ | 按钮样式 |

### 2.3 按钮样式

| type | 视觉效果 | 使用场景 |
|---|---|---|
| `primary` | 蓝色/绿色 | 确认、同意、提交等正向操作 |
| `danger` | 红色 | 拒绝、删除、取消等负向操作 |
| `default` | 灰色 | 查看详情、跳转等中性操作 |

### 2.4 按钮布局

按钮按二维数组组织:
- 外层数组的每个元素代表一行
- 内层数组的元素代表该行中的按钮
- 每行按钮水平排列，行与行之间垂直堆叠

```json
// 示例: 2行布局
// 第一行: [同意] [拒绝]
// 第二行: [查看详情]
"buttons": [
  [
    {"text": "同意", "action": "approve", "type": "primary"},
    {"text": "拒绝", "action": "reject", "type": "danger"}
  ],
  [
    {"text": "查看详情", "action": "view_detail", "type": "default"}
  ]
]
```

## 3. 按钮回调 API

### 3.1 端点

```http
POST /v2/buttons/callback
Content-Type: application/json
Authorization: Bearer <token>
```

### 3.2 请求体

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `msg_id` | String | ✅ | 消息ID（被点击的消息） |
| `to_type` | String | ✅ | 目标类型: `"direct"` (私聊) / `"group"` (群聊) |
| `to_id` | String | ✅ | 目标ID（用户ID或群组ID） |
| `btn_index` | int | ✅ | 按钮索引（从0开始，行优先排列） |
| `tid` | String | ✅ | 事务ID（UUID，用于追踪请求） |
| `nonce` | String | ✅ | 随机数（防重放攻击） |
| `action` | String | ✅ | 按钮动作标识 |
| `form_data` | String | ❌ | 表单数据（可选） |

### 3.3 请求示例

```json
{
  "msg_id": "msg_123",
  "to_type": "group",
  "to_id": "group_456",
  "btn_index": 0,
  "tid": "txn_789",
  "nonce": "random_abc123",
  "action": "approve",
  "form_data": null
}
```

### 3.4 响应

**成功**:
```json
{
  "status": "ok",
  "message": "操作已提交"
}
```

**错误**:
```json
{
  "status": "error",
  "code": 400,
  "message": "按钮已被点击"
}
```

## 4. btn_index 计算方式

`btn_index` 按行优先顺序排列，从0开始:

```
buttons[0][0] → index 0
buttons[0][1] → index 1
buttons[1][0] → index 2
buttons[1][1] → index 3
...
```

示例:
```json
"buttons": [
  [
    {"text": "同意", "action": "approve"},    // index 0
    {"text": "拒绝", "action": "reject"}      // index 1
  ],
  [
    {"text": "查看详情", "action": "detail"}   // index 2
  ]
]
```

## 6. 客户端实现

### 6.1 按钮数据模型

```java
public class InteractiveButton {
    private String text;    // 按钮文本
    private String action;  // 按钮动作
    private String type;    // 按钮类型: primary/danger/default
}

public class InteractiveMessage {
    private String text;                        // 消息文本
    private List<List<InteractiveButton>> buttons; // 按钮组
}
```

### 6.2 回调请求模型

```java
public class ButtonCallbackRequest {
    private String msg_id;      // 消息ID
    private String to_type;     // 目标类型
    private String to_id;       // 目标ID
    private int btn_index;      // 按钮索引
    private String tid;         // 事务ID
    private String nonce;       // 随机数
    private String action;      // 按钮动作
    private String form_data;   // 表单数据
}
```

### 6.3 按钮渲染逻辑

```java
// 渲染按钮行
for (List<InteractiveButton> row : message.getButtons()) {
    LinearLayout rowLayout = new LinearLayout(context);
    rowLayout.setOrientation(LinearLayout.HORIZONTAL);
    
    for (InteractiveButton btn : row) {
        Button button = new Button(context);
        button.setText(btn.getText());
        
        // 设置样式
        switch (btn.getType()) {
            case "primary":
                button.setBackgroundResource(R.drawable.btn_primary);
                break;
            case "danger":
                button.setBackgroundResource(R.drawable.btn_danger);
                break;
            default:
                button.setBackgroundResource(R.drawable.btn_default);
                break;
        }
        
        // 点击事件
        button.setOnClickListener(v -> {
            onButtonClicked(btn, calculateIndex(row, btn));
        });
        
        rowLayout.addView(button);
    }
    container.addView(rowLayout);
}
```

### 6.4 回调发送

```java
private void onButtonClicked(InteractiveButton btn, int index) {
    ButtonCallbackRequest request = new ButtonCallbackRequest();
    request.setMsg_id(message.getMsgId());
    request.setTo_type(message.getToType());
    request.setTo_id(message.getToId());
    request.setBtn_index(index);
    request.setTid(UUID.randomUUID().toString());
    request.setNonce(generateNonce());
    request.setAction(btn.getAction());
    
    api.sendButtonCallback(request).enqueue(new Callback<ApiResponse>() {
        @Override
        public void onResponse(...) {
            if (response.isSuccessful()) {
                // 按钮点击成功，禁用按钮
                disableButtons();
            }
        }
    });
}
```

## 7. 安全机制

### 7.1 事务ID (tid)

每个按钮点击请求都携带唯一的事务ID (UUID格式)，用于:
- 追踪请求
- 防止重复处理
- 日志记录

### 7.2 Nonce

随机数用于防止重放攻击:
- 每次点击生成新的随机数
- 服务端验证nonce唯一性

### 7.3 按钮禁用

按钮点击成功后，客户端应禁用所有按钮，防止重复点击。
