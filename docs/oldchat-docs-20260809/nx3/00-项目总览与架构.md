### 1.1 原生库变化

**正式版** 包含 Conscrypt 原生库 (4个ABI)，是 APK 体积 6.7MB 的主要原因:

| 库文件 | ABI | 说明 |
|---|---|---|
| libconscrypt_jni.so | arm64-v8a | 64位 ARM (主流设备) |
| libconscrypt_jni.so | armeabi-v7a | 32位 ARM (旧设备) |
| libconscrypt_jni.so | x86 | 32位 x86 (模拟器) |
| libconscrypt_jni.so | x86_64 | 64位 x86 (模拟器) |

**测试版** 移除了全部 Conscrypt 原生库，APK 体积降至 4.6MB。TLS 改用 Java 标准实现 + SpongyCastle 补充。

## 7. RegisterActivity 移除 (jadx 确认)

**旧版 (v1.3.61)**:
- `RegisterActivity` 包含完整注册表单：邮箱/密码/验证码/头像/协议勾选
- POST `/auth/register` 提交注册

**新版 (v1.4.x)**:
- `RegisterActivity` 已被移除
- `LoginActivity` 中点击注册按钮时通过以下方式跳转浏览器注册：
```java
Intent intent = new Intent(Intent.ACTION_VIEW, Uri.parse(base_url + "/register"));
startActivity(intent);
```
- 注册端点独立为 `/register`，不再通过 Activity 处理
