### 2.2 `bili_auth` — B站认证信息

**管理类**: `BiliAuthStore.java`

| 键名 | 类型 | 方法 | 说明 |
|---|---|---|---|
| `access_token` | String | `getAccessToken()` / `saveAuth()` | B站访问令牌 |
| `cookies` | String | `getCookies()` / `saveAuth()` | B站Cookie字符串 |
| `mid` | long | `getMid()` / `saveMid()` | 用户MID |
| `expires_at` | long | `isExpired()` / `saveAuth()` | 过期时间戳 (毫秒) |

**存储方法** (jadx 确认):

```java
// saveAuth() - 基础认证
prefs.edit()
    .putString("access_token", token)
    .putString("cookies", cookies)
    .putLong("expires_at", currentTime + expiresInSeconds * 1000)
    .apply();

// saveAuthWithMid() - 含MID的认证
prefs.edit()
    .putString("access_token", token)
    .putString("cookies", cookies)
    .putLong("expires_at", currentTime + expiresInSeconds * 1000)
    .putLong("mid", mid)
    .apply();

// saveMid() - 单独保存MID
prefs.edit()
    .putLong("mid", mid)
    .apply();

// clear() - 清除所有
prefs.edit().clear().apply();
```

**过期判断** (jadx 确认):
```java
public static boolean isExpired(Context context) {
    long expires = prefs(context).getLong("expires_at", 0L);
    return expires > 0 && System.currentTimeMillis() >= expires;
}
```

### 2.4 `user_name_cache` — 用户名缓存

**管理类**: `k0/G.java`

| 键名格式 | 类型 | 说明 |
|---|---|---|
| `name_{uid}` | String | 用户显示名 (≤15字符) |

**缓存策略** (jadx 确认):
- 内存缓存: `HashMap<String, String>` (f7571b)
- 磁盘缓存: SharedPreferences
- 名称截断: 超过15字符截断，换行符替换为空格
- 写入时机: 好友列表加载时批量写入
- 清除时机: 账号切换时 `a(context)` 清除

**名称解析优先级** (jadx 确认 `AbstractC0337g.c()`):
```
remark_name > display_name > username > uid
```

**批量写入** (jadx 确确认 `G.c()`):
```java
// 遍历好友列表，提取名称写入缓存
String name = AbstractC0337g.c(
    friend.remark_name,    // 优先: 备注名
    friend.display_name,   // 次选: 显示名
    friend.username,       // 再次: 用户名
    friend.uid             // 兜底: UID
);
edit.putString("name_" + friend.uid, name);
```

## 9. 数据安全

### 9.1 明文存储风险

| 数据 | 存储方式 | 风险等级 |
|---|---|---|
| access_token | SharedPreferences (明文) | 中 |
| refresh_token | SharedPreferences (明文) | 中 |
| saved_username | SharedPreferences (明文) | 低 |
| saved_password | SharedPreferences (**明文**) | **高** |
| user_id | SharedPreferences (明文) | 低 |
| my_ncuid | SharedPreferences (明文) | 低 |
| B站cookies | SharedPreferences (明文) | 中 |
| B站access_token | SharedPreferences (明文) | 中 |

### 9.2 备份风险

`allowBackup=true` 意味着通过 ADB 可以提取所有 SharedPreferences 和数据库文件。

### 9.3 建议

- 密码应使用加密存储 (如 EncryptedSharedPreferences)
- Token 应存储在 Android Keystore 加密的容器中
- 应设置 `allowBackup=false` 或排除敏感文件
