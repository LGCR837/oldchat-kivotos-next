# 09 - 频道系统 (dev2新增)

> 基于 jadx 反编译分析 (oldchat-dev-new.apk)  
> 更新时间: 2026年8月  
> 频道系统是 dev2 版本引入的全新社交功能模块

---

## 1. 概述

频道系统类似 Telegram Channel / Discord Forum，是一个一对多的内容发布平台。用户可以发现、订阅频道，接收频道管理员发布的帖子。

**功能特性**:
- 频道发现与搜索
- 频道订阅/取消订阅
- 通知级别设置（全部通知/静音）
- 频道帖子发布（支持媒体附件）
- 频道信息展示（订阅数、描述等）

---

## 2. 核心组件

### 2.1 Activities

| Activity | 功能 | 关联API |
|---|---|---|
| `ChannelActivity` | 频道详情页 | subscribe, unsubscribe, notifications, posts |
| `ChannelComposeActivity` | 频道发帖 | posts/send, media/upload |
| `ChannelDiscoveryActivity` | 频道发现/搜索 | channels/discover |

### 2.2 数据模型

**ChannelInfo (C0322b) — 频道信息**:

| 字段 | 混淆名 | 类型 | 说明 |
|---|---|---|---|
| `id` / `channel_id` | `f7522a` | String | 频道唯一ID |
| `name` | `f7523b` | String | 频道名称 |
| `handle` | `f7524c` | String | 频道句柄（类似Twitter handle） |
| `avatar_url` | `f7525d` | String | 频道头像URL |
| `description` | — | String | 频道描述 |
| `subscriber_count` | `f7528g` | int | 订阅者数量 |
| `role` | `f7532k` | String | 用户角色: `owner`/`admin`/`publisher`/`subscriber` |
| `last_read_at` | `f7534m` | long | 最后阅读时间戳 |
| `notification_level` | `f7535n` | String | 通知级别: `all`/`none` |
| `channel_subscribed` | — | boolean | 当前用户是否已订阅 |

**频道帖子模型 (C0321a)**:

| 混淆名 | 类型 | 说明 |
|---|---|---|
| `f7507c` | long | 帖子时间戳（用于已读同步） |

## 3. API 端点详解

### 3.1 GET `/v2/channels/discover` — 频道搜索/发现

**查询参数**:

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `q` | String | ❌ | 搜索关键词（为空则返回热门频道） |

**请求示例**:
```http
GET /v2/channels/discover?q=技术
Authorization: Bearer <token>
```

**成功响应**:
```json
{
  "channels": [
    {
      "id": "channel_001",
      "name": "技术交流",
      "handle": "tech_talk",
      "avatar_url": "/avatars/channel_001.png",
      "description": "技术讨论与分享",
      "subscriber_count": 1234,
      "notification_level": "all"
    }
  ]
}
```

---

**请求体**:

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `channel_id` | String | ✅ | 频道ID |

### 3.5 POST `/v2/channels/posts/send` — 发送频道帖子

**请求体**:

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `channel_id` | String | ✅ | 频道ID |
| `content` | String | ✅ | 帖子内容 |
| `media_refs` | Array | ❌ | 媒体引用列表 |
| `media_refs[].media_ref` | String | ✅ | 媒体引用ID（由上传接口返回） |
| `media_refs[].type` | String | ✅ | 媒体类型: `image`/`file` |

**请求示例**:
```json
{
  "channel_id": "channel_001",
  "content": "这是一条频道帖子",
  "media_refs": [
    {
      "media_ref": "media_789",
      "type": "image"
    }
  ]
}
```

**成功响应**:
```json
{
  "status": "ok",
  "post_id": "post_123",
  "message": "帖子发送成功"
}
```

---

### 3.6 POST `/v1/channels/media/upload` — 频道媒体上传

**Content-Type**: `multipart/form-data`

**请求参数**:

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `file` | binary | ✅ | 文件二进制数据 |
| `channel_id` | String | ✅ | 频道ID |

**成功响应**:
```json
{
  "url": "/uploads/channels/media/image_456.jpg",
  "media_ref": "media_789",
  "mime": "image/jpeg"
}
```

**响应字段**:

| 字段 | 类型 | 说明 |
|---|---|---|
| `url` | String | 媒体文件URL |
| `media_ref` | String | 媒体引用ID（用于发帖时引用） |
| `mime` | String | MIME类型 |

## 4. 频道角色权限

| 角色 | 说明 | 权限 |
|---|---|---|
| `owner` | 频道主 | 全部权限：发帖、管理成员、删除频道 |
| `admin` | 管理员 | 可发帖、管理成员 |
| `publisher` | 发布者 | 可发帖 |
| `subscriber` | 订阅者 | 只读，可查看帖子 |

## 6. Activity 实现细节

### 6.1 ChannelActivity — 频道详情页

**功能**:
- 显示频道信息（名称、头像、描述、订阅数）
- 订阅/取消订阅按钮
- 通知级别切换（铃铛图标）
- 帖子列表（RecyclerView）
- 发帖按钮（FloatingActionButton）
- 下拉刷新

**关键逻辑**:
```java
// 订阅/取消订阅
private void toggleSubscription() {
    if (isSubscribed) {
        api.unsubscribeChannel(channelId).enqueue(...);
    } else {
        api.subscribeChannel(channelId).enqueue(...);
    }
}

// 通知级别切换
private void toggleNotificationLevel() {
    String newLevel = "all".equals(notificationLevel) ? "none" : "all";
    api.setChannelNotification(channelId, newLevel).enqueue(...);
}
```

### 6.2 ChannelComposeActivity — 频道发帖

**功能**:
- 文本内容编辑
- 图片选择与上传
- 文件附件添加
- 帖子预览与发送

**上传流程**:
1. 选择文件
2. 计算SHA256
3. 调用 `/v2/files/check` 检查秒传
4. 如果已存在，直接使用URL
5. 如果不存在，调用 `/v1/channels/media/upload` 上传
6. 获取 `media_ref`
7. 构造帖子请求发送

### 6.3 ChannelDiscoveryActivity — 频道发现

**功能**:
- 搜索框（带防抖，300ms延迟）
- 频道列表（RecyclerView）
- 空状态提示
- 点击进入频道详情

## 7. SharedPreferences 缓存

| 键名 | 类型 | 说明 |
|---|---|---|
| `channel_subscribed_{channelId}` | boolean | 频道订阅状态本地缓存 |

**缓存策略**:
- 订阅/取消订阅后立即更新本地缓存
- 进入频道时先读取缓存快速显示状态
- 同时从服务器获取最新状态并更新缓存
