## A. 体验现状（先肯定做得好的）

| 维度 | 证据 | 评价 |
|---|---|---|
| 滚动体验 | `scrollToBottom`/底部锚点/`atBottom` 检测（L1288-1331）、会话切换 `scrollTop` 恢复（L4262-4468）、向上加载更多保留位置（L4510-4567、L5290-5353） | **扎实**，聊天滚动无跳变 |
| 消息渲染 | `appendMessage` 增量追加（L5158）、`convCache` 存 `DocumentFragment`（L3003）、加载更多前插 | **核心聊天是增量的**，不卡 |
| 图片兜底 | `onerror` → `default-avatar`/隐藏 普遍；封面 `loading="lazy"`（L2093） | 良好 |
| 微交互 | CSS 57 处 `transition`/`animation`；覆盖层 `rAF` 淡入 | 有质感 |
| 错误处理 | 229 处 `try/catch`、84 处 `showAlert`/`toast` 反馈 | 覆盖不错 |
| 右键菜单 | 31 处 `contextmenu`（复制 ID 等） | 有 |
| 主题 | 浅/深 `data-theme` + 持久化（L3143-3161） | 有切换，但不跟随系统 |

**结论**：主聊天链路（渲染/滚动/错误/图片）质量不差；问题集中在**二级面板重渲染、无障碍、响应式、加载态、输入节流**这几块。

## B. 体验短板（按影响排序，均附代码证据）

### B1. 无障碍几乎为零 ⚠️
`aria-` / `tabindex` / `role=` / `alt=` 全项目 **0 处命中**。
- 头像 `<img>` 无 `alt`；按钮无 `aria-label`；列表项不可键盘聚焦。
- 桌面 IM 工具对键盘导航、屏幕阅读器完全没做，属可用性与无障碍合规硬伤。

### B2. 二级面板整片 `innerHTML` 重建（68 处）
好友列表、音乐列表、动态、设置、群成员等每次数据变动**全量重绘**：
- 闪烁、丢失滚动位置与输入焦点、无过渡动画。
- 聊天主链路是增量的（好），但多数二级面板不是。长好友列表/长动态流体验更明显。

### B3. 响应式形同虚设
全 CSS 仅 **1 条** `@media (max-width: 768px)`（app.css L2263）。
- 窗口缩放、高分屏 DPI、窄窗下布局可能破。桌面 app 至少应保证最小窗口与 125%/150% 缩放下正常。

### B4. 输入无防抖/节流（0 处）
`debounce`/`throttle` 全 0。好友搜索（L5937）、音乐筛选等**每次按键即查**：
- 长列表卡顿 + 冗余请求。

### B5. 加载/空态薄弱
`loading|加载|spinner|骨架|empty|空状态|暂无` 仅 **15 处**。
- 大量异步面板（加载好友/动态/音乐）缺骨架屏、loading 占位、空数据提示；网络慢时白屏或内容突兀出现。

### B6. 主题不跟随系统
无 `prefers-color-scheme`。首次进入不读系统偏好；深色仅靠 `data-theme` 切换。
- 需确认所有 CSS 变量（含 `dumogu-scrollbar` 等第三方样式）在深色下都覆盖，否则局部发白。

### B7. 无统一键盘快捷键体系
发消息 `Enter`、切换会话、搜索、关闭弹窗等无统一快捷键。重度用户效率低。

### B8. 长会话无虚拟化/上限（待确认）
`convCache` 缓存 `DocumentFragment`，但未发现消息条数上限/回收逻辑；极长会话 DOM 持续累积，可能影响内存（切换会话时是否清理需实测确认）。

## C. 缺失功能（体验向补充视角）

在 `gap-analysis.md` 已列（B站/Lua/新闻/资源社区 P0；二维码/群公告/黑名单/全局搜索/设备管理 P1；表情商店/通话 P2）基础上，补**好用的 IM 客户端该有、且偏前端体验**的缺口：

1. **消息级状态**：发送中/失败重发按钮、撤回后编辑、转发、多选（批量删除/转发）、置顶消息、收藏。
2. **搜索体验**：聊天记录内搜索（v1.4 端点已给，可动手）、全局搜好友/群、音乐搜索（v1.4 `MusicSearchActivity`）。
3. **通知精细化**：目前是全局托盘闪烁，缺**按会话免打扰/静音**、@我/关键词高亮。
4. **表情与输入**：emoji 面板分类/最近使用、GIF、大表情动画；**输入框草稿自动保存**（切走再回不丢）。
5. **媒体体验**：图片多图九宫格预览、视频内联播放、语音消息波形+拖动进度、文件卡片下载进度。
6. **群体验**：群公告、群昵称、群成员搜索、入群欢迎。
7. **账号与多设备**：设备管理/远程登出、多端已读同步、多账号登录。
8. **可访问性/个性化**：深色跟随系统、字体大小调节、简繁/多语言（项目既定仅中文，记一笔）。

## D. 建议优先级（前端，不依赖腐竹）

### 【高 · 低成本高收益，建议先做】
- **无障碍基线**：头像/按钮加 `alt`/`aria-label`，列表项 `tabindex` 可聚焦，键盘可达。
- **加载/空态补齐**：异步面板加 loading 占位 + 空数据文案。
- **输入防抖**：搜索/筛选加 `debounce`（几十行）。
- **`Enter` 发送 + 基础快捷键**（发消息、切换会话、关闭弹窗）。

### 【中】
- **二级列表增量更新**：好友/音乐/动态改为 `replaceChild`/diff 或至少保留滚动位置，消除闪烁。
- **主题跟随系统** + 深色下第三方样式（scrollbar）复查。
- **按会话免打扰/静音** + **消息发送中/失败状态可视化**。

### 【低 / 大】
- 超长会话**消息虚拟化**。
- 表情面板升级、草稿保存、多图预览、语音波形。
- P1 功能落地（搜索、群公告等，接 v1.4 端点）。
