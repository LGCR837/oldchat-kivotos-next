Features

特性一览

为基沃托斯量身定制的功能，让聊天更贴近 Sensei 的日常。

桃信风格界面

延续《蔚蓝档案》中 MomoTalk 的界面风格，支持明暗主题切换，让 Sensei 仿佛置身于基沃托斯。

项目介绍

「OldChat For Kivotos Next」是专门为基沃托斯打造的第三方 OldChat 客户端，俗称 「桃信旧聊」。 本作是初代网页版的全新一代重写：界面风格得以延续，底层则从 Web 应用彻底重构为 Tauri 原生桌面客户端， 直连后端、免安装运行，使 Sensei 们也能在聊天中获得最好的体验。

作者

由 Aoharu Reverie（LGCR837）开发维护。
技术栈：前端 HTML + CSS + JS · 后端 Rust + Tauri v2 + JS
