## 7. RegisterActivity 移除 (jadx 确认)

**旧版 (v1.3.61)**:
- `RegisterActivity` 包含完整注册表单：邮箱/密码/验证码/头像/协议勾选
- POST `/auth/register` 提交注册

**新版 (v1.4.x)**:
- `RegisterActivity` 已被移除
- `LoginActivity` 中点击注册按钮时通过以下方式跳转浏览器注册：
```java
Intent intent = new Intent(Intent.ACTION_VIEW, Uri.parse(base_url + "/register"));
startActivity(intent);
```
- 注册端点独立为 `/register`，不再通过 Activity 处理
