### 1.2 核心类详解 (jadx 确认)

#### BiliApi — 完整API封装 (v1.4.x重构)

v1.4.x 将原来分散在 `a-f.java` 中的 B站 API 逻辑整合到 `BiliApi` 类中，包含7个内部类，覆盖了 B站 的主要功能:

| 内部类 | 推测功能 |
|---|---|
| 内部类1 | 视频相关API |
| 内部类2 | 评论相关API |
| 内部类3 | 用户相关API |
| 内部类4 | 搜索相关API |
| 内部类5 | 收藏相关API |
| 内部类6 | 历史记录API |
| 内部类7 | 推荐相关API |

#### BiliApiExtra — 扩展API (v1.4.x新增)

专门处理收藏、历史、评论等扩展功能的API调用。

#### BiliApiSupport0 / BiliApiSupport1 — 辅助API (v1.4.x新增)

提供辅助性的API调用支持。

#### BiliWbiSigner — Wbi签名算法 (v1.4.x新增)

v1.4.x 引入了 B站的 Wbi 签名算法，这是 B站 新版 API 的签名机制:

```
请求参数 → Wbi签名 → 签名后的参数 → 发送请求
```

Wbi签名用于防止请求伪造，是 B站 API 安全机制的重要组成部分。

#### BiliAuthStore — 认证存储 (v1.4.x新增)

管理 B站 的认证信息持久化:
- Cookie 存储 (BiliCookie: name, value, expires, httpOnly, secure)
- Token 管理
- 登录状态维护

#### BiliQrGenerator — 二维码生成 (v1.4.x新增)

专门用于生成 B站 登录二维码，替代了原来依赖外部库的方式。

#### BiliUserSpaceApi — 用户空间API (v1.4.x新增)

提供 B站 用户空间相关的 API 调用:
- 用户信息查询
- 用户视频列表
- 用户动态

#### BiliShareUtil — 分享工具 (v1.4.x新增)

提供 B站 内容分享功能:
- 视频分享链接生成
- 分享到其他平台

#### BiliSigner — 签名基类 (v1.4.x新增)

B站API签名的基类，`BiliWbiSigner` 继承此类。

### 1.3 QR码登录流程 (jadx 确认)

```
1. 获取QR认证码
   POST https://passport.bilibili.com/x/passport-tv-login/qrcode/auth_code
   参数: local_id=0, ts=时间戳, sign=BiliWbiSigner签名
   响应: QRAuthCodeResult (url, auth_code)

2. 展示二维码
   通过 BiliQrGenerator 生成二维码图片供用户扫描

3. 轮询扫码状态
   定期检查用户是否已扫码确认

4. 获取登录结果
   扫码成功后获取 cookies (BiliCookie列表)

5. 保存认证信息
   通过 BiliAuthStore 持久化 cookies，用于后续API调用
```

### 2.2 评论系统模型

```java
CommentData {
    List<CommentReply> replies;  // 评论列表
    List<CommentReply> hots;     // 热门评论
    CommentPage page;            // 分页信息
    CommentTop top;              // 置顶评论
    CommentUpper upper;          // UP主信息
}

CommentReply {
    long rpid;                    // 评论ID
    long parent;                  // 父评论ID
    long root;                    // 根评论ID
    CommentContent content;       // 内容 {message}
    CommentMember member;         // 用户 {uname, avatar}
    long ctime;                   // 时间戳
    int like;                     // 点赞数
    int rcount;                   // 回复数
    List<CommentReply> replies;   // 子回复
    boolean hotComment;           // 是否热评 (transient)
    boolean likedByMe;            // 是否已赞 (transient)
    boolean showAllReplies;       // 是否展开 (transient)
}
```

## 4. Lua小程序平台 (CIP)

### 4.1 平台架构

```
MiniAppsActivity (小程序列表/商店)
    ↓ 选择小程序
LuaMiniAppActivity (小程序运行容器)
    ↓ Lua脚本执行
CipVibeBackgroundService (后台执行服务)
    ├── Lua虚拟机
    ├── API桥接
    └── 生命周期管理

CipDevelopmentModeActivity (开发模式入口)
    ↓
CipVibeCodingActivity (在线编程环境)
    ├── 代码编辑器
    ├── 运行/调试
    └── configChanges=orientation|screenSize|keyboardHidden

CipDeveloperActivity (开发者工具)
```

### 4.2 CIP 平台组件

| 组件 | 功能 | 特点 |
|---|---|---|
| **MiniAppsActivity** | 小程序列表 | 展示可用小程序 |
| **LuaMiniAppActivity** | 小程序容器 | 运行Lua脚本的沙盒 |
| **CipVibeBackgroundService** | 后台服务 | 支持Lua脚本持续运行 |
