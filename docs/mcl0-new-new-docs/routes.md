# Oldchat 服务端非管理员 URL 路径清单

来源：`server/internal/http/api.go` 实际注册路由。

说明：
- 已排除根路径 `/admins/*` 管理后台路由；
- `/v2` 为主协议版本（支持 `POST /v2/gateway` 全链路加密折叠与直接调用）；
- `/v1` 保持向下兼容；
- `{name}` 表示路径参数，`*` 表示通配静态资源路径；
- `HANDLE` 表示静态资源文件服务。
