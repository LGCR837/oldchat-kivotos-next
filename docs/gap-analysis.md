## 一、已实现功能（与原版对比）

以下能力在客户端中已落地，覆盖了原版核心 IM 体验：

- 登录/注册（账号密码 + GeeTest 4.0 滑块 + QQ 邮箱注册）
- 私聊：文本 / 图片 / 文件 / 语音 / 引用 / @提及 / 撤回 / 阅后即焚 / 红包 / 已读
- 群聊：群成员、@全体、群管理（邀请/成员）、撤回
- 联系人：好友列表、好友申请、添加好友、群列表
- 个人空间 + 动态/朋友圈（瀑布流、点赞、评论、发布动态）
- 签到墙（含评论互动）
- 音乐：广场 / 排行 / 我的，TTML + LRC 双格式歌词，播放控制、单曲循环
- 主题（浅色/深色）、通知（托盘 + 任务栏闪烁）
- 图片查看器（缩放/拖拽/滚轮/保存）、表情（本地 emoji + 广场入口）
- WebSocket 实时通信，且实现了 **ECDH P-256 + AES-CBC 信封加密**（WS 层，app.js L1029 / L3270-L3407）
- 用户资料缓存与并发去重、IndexedDB 媒体缓存

## 二、残缺 / 缺失功能清单

### P0 — 完全缺失的整块功能域（原版有，客户端零实现）

| 功能 | 原版入口 | 客户端证据 | 影响 |
|---|---|---|---|
| **B站集成（OldView）** | OldViewActivity 等 7 个页面、二维码登录、评论、收藏夹、历史 | `bili/bilibili/BV` 仅 3 处误匹配，无实现 | 无法看 B站视频流、评论、UP主、收藏 |
| **Lua 小程序（CIP）** | MiniAppsActivity、LuaMiniAppActivity、在线编程、后台执行 | `lua/小程序/cip/Lua` 仅 5 处误匹配 | 无小程序生态、无"Vibe Coding" |
| **极简新闻** | MinimalNewsActivity / Detail | `news/新闻` 仅 5 处误匹配 | 无新闻聚合 |
| **资源分享社区** | ResourceSectionsActivity 等分区/资源/评论 | `resource/资源分区` 仅 5 处（实为 upload 等） | 无资源分区浏览与社区互动（仅有聊天内发文件） |

### P1 — 缺失的社交 / 管理功能

| 功能 | 客户端证据 | 说明 |
|---|---|---|
| **二维码（名片/扫码）** | `二维码/扫码/qrcode/scan` 零匹配 | 无法生成名片二维码，无法扫码加好友/加群 |
| **群公告** | `公告/announce/群公告` 零匹配 | 群管理面板有成员/邀请，但无公告发布 |
| **黑名单 / 拉黑** | `拉黑/blacklist/blockUser` 零匹配（22 处 block 均为 CSS display:block、blocking_save_file 等误匹配） | 无法拉黑/屏蔽用户 |
| **全局搜索** | `search` 仅 15 处，且只是 @提及 内的"全拼/拼音首字母搜索"（L5937/L5940） | 无好友/群/聊天记录全局搜索。**v1.4.x 已提供 `/direct/messages/search`、`/groups/messages/search` 端点，聊天记录搜索现已可实现**，详见适配计划 §2.1 |
| **设备管理 / 远程登出** | 代码中未见设备列表/远程登出 | 原版 DeviceManagementActivity 缺失 |
| **隐私政策页** | 未见 | 原版 PrivacyPolicyActivity 缺失 |

### P2 — 半残 / 未完全对接

| 功能 | 现状 | 不足 |
|---|---|---|
| **表情商店** | 有 emojiPlaza 本地表情 + 广场入口按钮 | 未对接表情包下载/商店，无法获取更多表情 |
| **HTTP API 加密** | WS 层已做 ECDH 信封加密 | REST 请求体疑似仍为明文 JSON，未对接 `X-Enc` 会话加密；全程 `http://` 明文传输（与原版一致，但仍是安全短板） |
| **实时通话** | 仅语音消息 | 无语音/视频通话（原版权限暗示可能有，但 nx 文档未确认，存疑） |

## 三、工程质量短板

1. **单文件架构**：全部逻辑在 `src/app.js`（7372 行）、`src/app.css`（3032 行），全局函数污染，维护/协作困难。
2. **无类型系统**：纯 JS，无 TypeScript，重构风险高。
3. **无自动化测试**：无单元/集成测试，回归靠手测。
4. **无打包优化**：直接静态文件交付，未压缩、未做 tree-shaking。
5. **仅 Windows 验证**：虽 Tauri 跨平台，但只测过 Windows。
   ↳ 2026-08-08 补了启动期环境自检（`src-tauri/src/preflight.rs`），覆盖 Windows/Linux 的 WebView
   运行时、图形环境、托盘依赖，缺依赖时弹原生窗口引导安装。**但 Linux 分支仍未实机验证。**
6. **无自动更新**：未配置 Tauri updater，发版靠手动替换 exe（build/ 下有 v1~v3 产物）。
7. ~~**废弃代码残留**：浏览器模式（Nginx 反代）已废弃但代码保留未清理。~~
   ✅ **已于 2026-08-08 清理**：移除 `_proxyOn`、端点三元分支、`oc_proxy_mode`、登录页「代理模式」复选框、
   `getApiBase()` 反代分支、关于页「浏览器 (Nginx)」文案；删除 `conf/`、`nginx.exe`、`run.bat`、
   `config.json`、`logs/`、`temp/`。`IS_TAURI` 保留为 Tauri API 可用性守卫。
8. **无代码规范**：无 ESLint / Prettier / 提交规范。

## 四、安全风险

- **传输明文**：全程 `http://`，密码/Token 在链路明文（与原版 `usesCleartextTraffic=true` 一致，但第三方客户端更应重视）。
- **本地存储明文**：`access_token`/`refresh_token`/账号密码存于 `localStorage` 明文（登录页"记住账号"会存明文密码）。
- **加密范围有限**：仅 WebSocket 信封加密，HTTP REST 未加密；加密密钥是否每连接轮换、HMAC 完整性校验是否完备需进一步核实。
- **无证书固定 / 无反调试**：中间人风险。

## 五、建议优先级（若要继续完善）

1. **【高】补齐 P0 整块功能**（尤其 B站集成、资源社区）— 工作量大，需先确认后端是否仍提供对应接口。
2. **【高】二维码名片/扫码** — 成本低、收益高，社交裂变基础能力。
3. **【中】群公告、黑名单、全局搜索** — 社交刚需，单点功能，可增量做。
4. **【中】HTTP 层会话加密（X-Enc）+ 本地凭证加密存储** — 安全补课。
5. **【低】工程管理**：拆分 app.js 模块、引入 TS/ESLint/Vite、加测试、配置 Tauri updater。
6. **【低】清理废弃的浏览器模式代码**，减少维护噪音。
