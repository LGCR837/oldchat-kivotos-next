## 2. SharedPreferences 详细分析

### 2.1 auth — 认证信息

| 键名 | 类型 | 说明 |
|---|---|---|
| `access_token` | String | API认证Bearer Token |
| `refresh_token` | String | Token刷新令牌 |
| `user_id` | String | 用户数据库ID |
| `my_uid` | String | 用户唯一标识UID |
| `saved_username` | String | 记住的用户名 (**明文**) |
| `saved_password` | String | 记住的密码 (**明文**) |
| `token` | String | 旧版token键名 (兼容) |

**读取示例** (来自 MainActivity):
```java
SharedPreferences sp = getSharedPreferences("auth", 0);
String token = sp.getString("access_token", null);
if (token == null) token = sp.getString("token", null); // 兼容旧版
```

**写入示例** (来自 LoginActivity):
```java
sp.edit()
  .putString("access_token", token)
  .putString("refresh_token", refreshToken)
  .putString("user_id", userId)
  .putString("my_uid", uid)
  .apply();
```

### 2.2 好友请求缓存 (i0.b)

| 键名 | 类型 | 说明 |
|---|---|---|
| 好友请求未读数 | int | 本地缓存的好友请求数量 |

- `i0.b.b(context)` — 读取缓存的好友请求数
- `i0.b.c(context, count)` — 写入缓存的好友请求数

### 2.3 通知已读状态 (i0.f)

| 键名 | 类型 | 说明 |
|---|---|---|
| 通知已读ID | Set/String | 已读通知的ID记录 |

- `i0.f.c(context, id)` — 检查通知是否已读
- `i0.f.d(context, id)` — 标记通知为已读

### 2.4 用户偏好

| SP名称 | 管理类 | 说明 |
|---|---|---|
| (未知) | `o0.V` | 隐私协议同意状态、用户偏好 |
| (未知) | `o0.U` | 服务器Base URL配置 |

- `V.g(context)` — 检查是否WiFi环境
- `V.l(context)` — 检查是否已同意隐私协议
- `V.y(context, agreed)` — 设置隐私协议同意状态
- `U.b()` — 获取当前服务器URL
- `U.f(context, url)` — 保存服务器URL
- `U.e(context)` — 恢复默认服务器URL

## 4. 文件存储

### 4.1 音乐缓存

| 属性 | 值 |
|---|---|
| 路径 | `{filesDir}/music_player_cache/` |
| 命名 | SHA1(url) + 扩展名 |
| 上限 | 220MB / 120个文件 |
| 清理 | LRU策略，后台线程自动清理 |
| 支持格式 | .mp3, .m4a, .aac, .amr, .3gp, .wav, .ogg, .flac |

**SHA1 命名算法**:
```java
byte[] digest = MessageDigest.getInstance("SHA1").digest(url.getBytes("UTF-8"));
StringBuilder sb = new StringBuilder(digest.length * 2);
for (byte b : digest) {
    int i = b & 0xFF;
    if (i < 16) sb.append('0');
    sb.append(Integer.toHexString(i));
}
return sb.toString() + extension;
```

**缓存清理** (l0方法):
1. 获取 `music_player_cache` 目录下所有文件
2. 按修改时间排序 (LRU)
3. 如果总大小 > 220MB 或文件数 > 120，从最旧开始删除
4. 播放时自动更新文件的 `lastModified` 时间

### 4.2 文件提供者 (FileProvider)

```xml
<provider
    android:name="android.support.v4.content.FileProvider"
    android:authorities="com.im.oldchat.fileprovider"
    android:exported="false"
    android:grantUriPermissions="true">
    <meta-data
        android:name="android.support.FILE_PROVIDER_PATHS"

```

用于安全地分享文件给其他应用（如图片分享、文件上传等）。

## 5. 数据模型

### 5.1 B站数据模型 (BiliModels.java)

#### BiliResponse<T> — 通用响应
```java
public static class BiliResponse<T> {
    public int code;       // 状态码
    public T data;         // 数据
    public String message; // 消息
    public int ttl;        // 过期时间
}
```

#### BiliCookie — Cookie
```java
public static class BiliCookie {
    public String name;
    public String value;
    public long expires;
    @A.c("http_only") public int httpOnly;
    public int secure;
}
```

#### CommentData — 评论数据
```java
public static class CommentData {
    public List<CommentReply> replies; // 评论列表
    public List<CommentReply> hots;    // 热门评论
    public CommentPage page;           // 分页
    public CommentTop top;             // 置顶评论
    public CommentUpper upper;         // UP主信息
}
```

#### CommentReply — 评论回复
```java
public static class CommentReply {
    public long rpid;                    // 评论ID
    public long parent;                  // 父评论ID
    public long root;                    // 根评论ID
    public CommentContent content;       // 内容
    public CommentMember member;         // 发表者
    public long ctime;                   // 创建时间
    public int like;                     // 点赞数
    public int rcount;                   // 回复数
    public List<CommentReply> replies;   // 子回复
    public transient boolean hotComment; // 是否热评
    public transient boolean likedByMe;  // 是否已赞
    public transient boolean showAllReplies; // 是否显示全部回复
}
```

#### CommentMember — 评论用户
```java
public static class CommentMember {
    public String uname;  // 用户名
    public String avatar; // 头像URL
}
```

#### CommentPage — 分页
```java
public static class CommentPage {
    public int count; // 总数
    public int num;   // 当前页
    public int size;  // 每页大小
}
```

### 5.2 数据注解

应用使用自定义注解 `@A.c` 进行JSON字段映射:
```java
@A.c("http_only") public int httpOnly;
// 将JSON中的 "http_only" 映射到 Java 字段 httpOnly
```

这是一种轻量级的JSON序列化方案，类似于 Gson 的 `@SerializedName`。

## 6. 缓存策略

### 6.1 内存缓存

- 全局 Context: `OldChatApplication.f2156a`
- 连接状态: `g0.j` 单例
- 上传状态: `ResourceUploadService.f2313h` (静态)

### 6.2 磁盘缓存

| 缓存类型 | 位置 | 策略 |
|---|---|---|
| 音乐缓存 | filesDir/music_player_cache/ | LRU, 220MB上限 |
| 图片缓存 | (推测在cacheDir) | 系统自动管理 |
| 数据库 | databases/ | 应用管理 |

### 6.3 网络缓存

- 好友请求计数: 本地缓存优先，网络失败时使用缓存 (`i0.b`)
- 通知已读状态: 本地持久化 (`i0.f`)
- 服务器URL: 本地持久化 (`o0.U`)

## 7. 数据安全

### 7.1 明文存储风险

| 数据 | 存储方式 | 风险等级 |
|---|---|---|
| access_token | SharedPreferences (明文) | 中 |
| refresh_token | SharedPreferences (明文) | 中 |
| saved_username | SharedPreferences (明文) | 低 |
| saved_password | SharedPreferences (**明文**) | **高** |
| user_id | SharedPreferences (明文) | 低 |

### 7.2 备份风险

`allowBackup=true` 意味着通过 ADB 可以提取所有 SharedPreferences 和数据库文件:
```bash
adb backup -f oldchat.ab com.im.oldchat
```

### 7.3 建议

- 密码应使用加密存储 (如 EncryptedSharedPreferences)
- Token 应存储在 Android Keystore 加密的容器中
- 应设置 `allowBackup=false` 或排除敏感文件
