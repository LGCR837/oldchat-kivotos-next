## 新增：转发聊天记录(forward_v2)折叠卡片
- 需求：兼容 `{"v":2,"text":"[聊天记录] 共N条","forward_v2":{"title":...,"items":[...]}}` 格式，但气泡内不直接展示完整内容，点开才展开详情。
- 之前：该 JSON 仅把 `obj.text`("[聊天记录] 共4条")当普通文本渲染，且会话列表 `messagePreview` 会显示整段原始 JSON。
- 实现（仅 app.js + app.css，纯前端）：
  - `createMessageElement` 的 `obj.v===2` 分支内新增 `if (obj.forward_v2)`：渲染 `.forward-card` 折叠卡（标题+前3条预览+"点击查看完整聊天记录 ›"），数据用 `encodeURIComponent(JSON.stringify(fwd))` 存入 `data-forward`，避免重解析。其余 v2 文本/引用/嵌套文件逻辑包进 `else`。
  - 全局委托 `document` click 监听 `.forward-card` → `openForwardModal(fwd)`：弹 `.custom-modal-overlay`（复用现有样式，`.forward-modal{max-width:460px}`），列表每行头像+昵称+正文（image/voice/file 类型降级显示占位），点遮罩或"关闭"关闭。
  - `messagePreview(d)` 增加：body 以 `{` 开头且含 `forward_v2` 时返回 `"标题（共N条）"`，避免会话列表显示原始 JSON。
- 配色走主题变量（`--panel-bg`/`--border`/`--accent`/`--hover`/`--text`），深/浅色与三主题均自适应。node --check 通过。尚未 git commit。
