## 3. 架构概览

### 3.1 启动流程

```
用户点击图标
    ↓
SplashActivity (启动页, LAUNCHER)
    ↓ 检查登录状态
    ├── 未登录 → LoginActivity
    └── 已登录 → MainActivity
                    ↓
                底部4Tab导航
                ├── 聊天 (Fragment)
                ├── 好友 (Fragment)
                ├── 发现 (Fragment)
                └── 我的 (Fragment)
```

### 3.3 混淆策略

代码经过ProGuard/R8混淆处理。核心业务类（Activity、Service、Application）保留原始类名，但内部字段和辅助类被重命名为短字母（如 `a`, `b`, `C0212c` 等）。这表明使用了保留类名的混淆规则，但成员变量和私有方法被深度混淆。
