#### 1.2.2 播放流程

```
1. 接收 PLAY_SONG Intent
2. 解析歌曲信息 (name, url, cover, lyrics, owner等)
3. 检查是否同一首歌 (URL比较)
   ├── 是: 更新元数据，继续播放
   └── 否: 停止当前播放，开始新歌
4. 检查本地缓存
   ├── 有缓存: 从文件播放 (U方法)
   └── 无缓存: 流式播放 (V方法) + 后台缓存
5. 设置 MediaPlayer:
   - AudioAttributes: USAGE_MEDIA, CONTENT_TYPE_MUSIC
   - 数据源: 文件路径 或 URL
   - 监听器: OnPrepared, OnCompletion, OnError
6. prepareAsync → onPrepared → start
7. 启动进度更新线程 (500ms间隔)
8. 显示前台通知
```

#### 1.2.3 缓存策略

**缓存目录**: `{filesDir}/music_player_cache/`

**缓存文件命名**: `SHA1(url) + 扩展名`

**扩展名检测**:
```java
String[] extensions = {".mp3", ".m4a", ".aac", ".amr", ".3gp", ".wav", ".ogg", ".flac"};
// 从URL中提取扩展名，未匹配则使用 ".cache"
```

**缓存条件**:
- WiFi环境: 自动缓存 (`d0` 方法检查)
- 非WiFi: 仅在用户主动下载时缓存

**缓存清理** (LRU):
- 最大大小: 220MB (230686720 bytes)
- 最大文件数: 120
- 清理策略: 按 `lastModified` 排序，删除最旧的
- 触发时机: 每次播放开始时检查

#### 1.2.4 音频焦点管理

```java
public void onAudioFocusChange(int focusChange) {
    if (focusChange == AUDIOFOCUS_LOSS_TRANSIENT) {
        // 暂时失去焦点 (如来电)
        f2287t = isPlaying();
        pause();
    } else if (focusChange == AUDIOFOCUS_LOSS) {
        // 永久失去焦点
        f2287t = false;
        pause();
    } else if (focusChange == AUDIOFOCUS_GAIN && f2287t) {
        // 重新获得焦点
        f2287t = false;
        play();
    }
}
```

**请求焦点**: `AudioManager.requestAudioFocus(this, STREAM_MUSIC, AUDIOFOCUS_GAIN)`

#### 1.2.5 通知栏控制

通知包含三个操作按钮:

| 按钮 | Action | 图标 |
|---|---|---|
| 播放/暂停 | TOGGLE_PLAY | ic_media_play/pause |
| 单曲循环 | TOGGLE_REPEAT_ONE | ic_menu_rotate |
| 关闭 | STOP | ic_menu_close_clear_cancel |

通知显示信息:
- 标题: 歌曲名称 (默认 "旧聊音乐")
- 内容: 播放状态 ("歌曲加载中"/"正在后台播放"/"已暂停"/"等待播放")

#### 1.2.6 错误处理

```
播放失败
    ↓ 检查是否有备用URL
    ├── 有: 尝试备用URL (n0方法, A.j获取)
    └── 无: 显示错误，停止播放
```

缓存文件损坏时自动删除并回退到流式播放。

## 2. 资源上传系统

### 2.1 ResourceUploadService 详细分析

#### 2.1.1 上传流程

```
1. 接收 RESOURCE_UPLOAD_START Intent
2. 检查是否忙碌 (l()方法)
   ├── 忙碌: 返回 "upload_busy" 错误
   └── 空闲: 继续
3. 检查网络状态 (G.d().f())
   ├── 不可用: 返回 "network_unavailable"
   └── 可用: 继续
4. 检查认证Token
   ├── 无Token: 返回 401 "no_token"
   └── 有Token: 继续
5. 构造上传请求:
   - 数据源: ContentResolver.openInputStream(uri)
   - 参数: section_id, file_name, content_type
   - API: POST /resources/upload
6. 启动前台通知 (进度条)
7. 执行上传 (g0.d.U方法)
8. 进度回调 → 更新通知 + 发送广播
9. 完成/失败 → 发送广播 + 停止服务
```

#### 2.1.2 进度计算

```java
// 每300ms或进度变化时更新
if (progress != lastProgress || now - lastUpdate >= 300) {
    // 计算上传速度 (每500ms采样)
    if (now - speedSampleTime >= 500) {
        speed = (uploaded - lastUploaded) * 1000 / (now - speedSampleTime);
    }
    // 更新通知和广播
}
```

#### 2.1.3 并发控制

使用静态锁机制:
```java
public static final Object f2312g = new Object(); // 锁对象
public static e f2313h; // 当前上传状态

public static boolean l() {
    synchronized (f2312g) {
        return f2313h != null && f2313h.f2343g; // 正在上传中
    }
}
```

同一时间只允许一个上传任务。

## 3. 图片处理

### 3.1 自定义控件

- **ZoomImageView**: 支持双指缩放的图片视图
  - 用于图片预览 (ImagePreviewActivity)
  - 支持手势缩放和拖动

- **RoundedImageView**: 圆角图片控件
  - 用于头像、缩略图显示

### 3.2 图片加载

应用未使用 Glide/Picasso 等第三方图片加载库，推测使用自定义实现或 OkHttp 直接加载。

### 3.3 图片预览

`ImagePreviewActivity` 提供全屏图片预览功能，支持:
- 全屏显示
- 双指缩放
- 保存到本地
