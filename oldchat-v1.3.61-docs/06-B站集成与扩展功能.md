### 1.2 QR码登录流程

**类**: `com.im.oldchat.bili.a` (extends `d`)

```
1. 获取QR认证码
   POST https://passport.bilibili.com/x/passport-tv-login/qrcode/auth_code
   参数: local_id=0, ts=时间戳, sign=签名
   响应: QRAuthCodeResult (url, auth_code)

2. 展示二维码
   将URL生成二维码图片供用户扫描

3. 轮询扫码状态
   定期检查用户是否已扫码确认

4. 获取登录结果
   扫码成功后获取 cookies (BiliCookie列表)

5. 保存认证信息
   将cookies保存到本地，用于后续API调用
```

**签名算法**: `h0.d.b(params)` — 对请求参数进行签名

**HTTP封装**: `c.j(url, params, cookie)` — 带Cookie的GET请求

### 1.3 数据模型详解

## 2. Lua小程序平台 (v1.3.61新增)

### 2.1 平台架构

这是 v1.3.61 最重大的功能新增，构建了一套完整的 Lua 小程序运行环境。

```
MiniAppsActivity (小程序列表/商店)
    ↓ 选择小程序
LuaMiniAppActivity (小程序运行容器)
    ↓ Lua脚本执行
CipVibeBackgroundService (后台执行服务)
    ├── Lua虚拟机
    ├── API桥接
    └── 生命周期管理

CipDevelopmentModeActivity (开发模式入口)
    ↓
CipVibeCodingActivity (在线编程环境)
    ├── 代码编辑器
    ├── 运行/调试
    └── configChanges=orientation|screenSize|keyboardHidden

CipDeveloperActivity (开发者工具)
```

### 2.2 CIP 平台组件

| 组件 | 功能 | 特点 |
|---|---|---|
| **MiniAppsActivity** | 小程序列表 | 展示可用小程序 |
| **LuaMiniAppActivity** | 小程序容器 | 运行Lua脚本的沙盒 |
| **CipVibeBackgroundService** | 后台服务 | 支持Lua脚本持续运行 |
| **CipDevelopmentModeActivity** | 开发入口 | 进入开发模式 (adjustPan) |
| **CipVibeCodingActivity** | 在线编程 | 代码编辑器，支持屏幕旋转 |
| **CipDeveloperActivity** | 开发者工具 | 调试/测试工具 (adjustUnspecified) |

### 2.3 技术特点

- **Lua运行时**: 应用内嵌Lua解释器
- **configChanges**: CipVibeCodingActivity 配置了 `orientation|screenSize|keyboardHidden`，说明它是一个全功能编辑器，自行处理配置变化
- **后台执行**: CipVibeBackgroundService 支持小程序在后台持续运行
- **沙盒安全**: 小程序在受控环境中运行

### 2.4 "CIP" 含义推测

- **C**hat **I**ntegrated **P**latform — 聊天集成平台
- 或 **C**ode **I**n **P**lace — 就地编码
- "Vibe Coding" 暗示这是一种低代码/可视化/自然语言编程方案

### 2.5 生态系统类比

这套系统类似于:
- 微信小程序
- QQ小程序
- Telegram Mini Apps

但使用 Lua 而非 JavaScript 作为脚本语言，这在社交应用中较为少见。
